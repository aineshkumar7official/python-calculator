# Simple CLI Calculator

A Python command-line calculator built for COP 2510. Version 2.0 supports multi-line operations and advanced trigonometry.

🚀 How to Run
Make sure you have Python installed, then run the calculator from your terminal:

```bash
python calculatorv2.py
```

🧮 Supported Operations

### Core Operations (v1.0)
* **Addition** (`+`)
* **Subtraction** (`-`)
* **Multiplication** (`*`)
* **Division** (`/`)
* **Exponents** (`^`)
* **Modulus** (`%`)
* **Square Root** (`sqrt`)
* **Logarithms** (`log`)

### New Operations (v2.0)
* **Multi-Line:** Chain multiple sequential operations together.
* **Trigonometry:** Sine (`sin`), Cosine (`cos`), and Tangent (`tan`).
