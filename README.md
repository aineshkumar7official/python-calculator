# Simple CLI Calculator

A Python command-line calculator built for COP 2510. Version 1.0 supports single-operation equations.

## 🚀 How to Run

Make sure you have Python installed, then run the calculator from your terminal:

```bash
python calculatorv1.py
```

## 🧮 Supported Operations
* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Exponents (`^`)
* Modulus (`%`)
* Square Root (`sqrt`)
* Logarithms (`log`)
